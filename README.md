## Practice Repository

This repository is used for practicing the basic GitHub workflow:
creating an issue, making a change, and opening a pull request.

## What this project is for

This project is part of a hometask to simulate a real contribution
cycle in an open source project. Students will:

- Create a new repository
- Open an issue describing an improvement
- Update the README file
- Open a pull request that closes the issue

## How to use this repository

1. Open an issue describing what should be improved in the README.
2. Edit this README file and implement the improvement.
3. Create a pull request and link it to the issue.
4. Review and merge the pull request.
